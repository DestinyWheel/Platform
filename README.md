# Platform

私人桌游平台（BGA 风格），游戏以插件形式存在，**新增/升级游戏不需要重启服务，也不需要重新发布前端**。

## 文档

- [架构规划](docs/architecture.md) —— 前后端框架、插件契约、热加载流程、数据模型、里程碑

## 状态

规划阶段。已定决策见 `docs/architecture.md` 文首。

## 核心思路

把每局游戏建模成「**可序列化状态 + 纯函数 reducer + 事件日志**」，进程里不留任何长驻游戏对象；游戏代码按版本隔离在 worker 中，升级 = 起新 worker + 切换版本指针，运行中的旧桌继续用旧版本直到结束。
