# 花砖物语：对决（Azul Duel）插件

规则来源：根目录 `EN_AzulDuel_Rulebook_compressed.pdf`。

## 实现结构

```
games/azul-duel/
  manifest.json
  src/plates.ts     # 18 块穹顶板、20 个奖励片、8 种计分目标
  src/server.ts     # 工厂、图案行、穹顶、阶段 2、五轮结算
  src/client.ts     # 工厂 / 展示板 / 双方板面
```

## 已实现的规则

- 5 色 × 13 = 65 普通砖（深蓝 / 青绿 / 黄 / 红 / 黑）+ 9 特殊砖 + 1 先手砖。
- 4 个小工厂 + 大工厂；小工厂月亮上有奖励片，太阳+月亮都空了才翻开。
- 20 个奖励片按实物双色搭配录入（5 色各出现 6 个半片，白色半片 10 个）；同色 2 片或任意 3 片可以替代一条图案行里缺的 1 块砖。白色半片本身不匹配任何砖色。
- 开局双方各选 1 块穹顶板；之后前四轮每轮每人用 2 个玩家棋子拿板。
- 行动：拿可见板 / 付 1 分抽背面板 / 拿工厂太阳某色 / 拿所有月亮顶部某色 / 拿奖励片。
- 拿大工厂月亮的人拿先手砖；先手砖每轮结束 -2，并决定下一轮先手。
- 图案行 1..6（容量 1..6）；拿到的砖只能进一条图案行，放不下的进破损区。
- 阶段 2：完整图案行最右砖铺到对应穹顶行的同色/万能格；孤立 1 分，否则横向连通数 + 纵向连通数。
- 特殊板填满 3 个颜色格后自动放特殊砖，按该行行号得分；特殊砖之后参与相邻连通。
- 破损区 1/2/3/4 块分别扣 1/3/6/10 分；分数不低于 0。
- 五轮后按计分板结算；平局由先手砖持有者获胜。

## 数据取舍

- **18 块穹顶板、20 个奖励片、4 张双面计分板**：都已按用户核对的实物数据录入。
- **计分板**：4 张板按 PDF 的上下两行配对（正面 / 反面）。入门用前 3 张板的正面（横线 3 / 竖线 7 / 对角线 10）；“完整”模式给 4 张板各随机翻一面，共 4 个目标。四角板：左上/右上角每块 3 分，左下/右下角每块 8 分。
- **视觉**：不使用图片。砖块是圆形：底色用对应颜色，图案挖白并带同色描边（黄=土太阳、红=火、深蓝=水、青绿=冰）；黑色砖按星球图案自身的白色区域填白——星球面被光环分成上下两个半圆，外圈是空心飞盘，外面保持黑砖；特殊砖是石色圆砖 + 白圈，万能格是五色线稿五角星（一个角一种颜色）。穹顶板打印格用浅色纸面 + 对应颜色线稿。奖励片由两块半砖拼接：每半显示对应颜色图案的一半，红色永远在右半块；数据里的白色半块在界面上用特殊砖的一半（石色 + 白圈）显示。袋、塔、计分板不显式展示，先手标记简化为「① 玩家/工厂」。
- **背面板堆**：展示区会画出板堆，堆顶显示背面类型（joker / special），因为规则允许花 1 分抽取背面向上的穹顶板。
- **抽背面板**：v1 简化为付 1 分抽 1 张直接放；原规则可以连续抽多张再选 1 张，留作 TODO。
- **阶段 2**：原规则双方同时处理；数字版按先手→后手顺序处理，双方操作互不影响。
