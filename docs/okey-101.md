# 土耳其麻将 · 101 Okey 插件

基础规则参考：okey.gg 的 101 Okey 规则、Pagat 的 Okey 101 页面。

用户确认的玩法是 **101 Okey**：

- 开局要“破冰”：累计 ≥101 分的牌组，或 ≥5 个对子，才能第一次开牌。
- 牌型至少 3 张。
- 开牌后可以拆场上已有牌型，和刚拿到的牌重新组成新牌型；拆完后每个普通牌型不能少于 3 张。
- 最后一条是具体 App/房规，不是所有 101 Okey 规则书都写；本插件按用户要求实现。

## 实现结构

```
games/okey-101/
  manifest.json
  src/tiles.ts     # 106 张牌、Okey/假百搭判定
  src/meld.ts      # set / run / pair 校验，服务端和客户端共用
  src/server.ts    # 发牌、摸打、开牌、拆牌重组、计分
  src/client.ts    # 牌桌、手牌、牌型构建器
```

## 已实现的规则

- 106 张：4 色（红/黄/蓝/黑）× 1..13 × 2 + 2 张假百搭。
- 指示牌同色 +1 为 Okey（13→1）；真 Okey 万能；假百搭当 Okey 本身、不万能。
- 庄家 22 张、其余 21 张；庄家先弃一张。
- 每回合摸牌或吃上家弃牌，然后必须弃一张。
- 牌型：同点数不同花色 3–4 张；同花色连续 3+ 张；1 只能最小，12-13-1 不合法；对子同色同点 2 张。
- 开牌：固定 101 分或 5 对，路线锁定。
- 开牌后可向场上牌型加牌；`rearrange` 提交**完整的桌上新分组**，服务端校验：
  - 桌上牌物理 id 多重集合不变（不能把桌上的牌拿走）；
  - 新牌只能来自手牌；
  - 普通路线每组 set/run 合法且 ≥3；对子路线每组对子 2 张；
  - 拿到的弃牌必须在本回合用进新分组。
- 胡牌（弃掉最后一张）本轮结束：赢家 -101；未开牌对手 +202；已开牌按剩余点数。
- 牌堆摸完无人胡：未开牌 +202、已开牌按剩余；没人开牌则本轮不记分。
- 默认 3 轮，可开桌选 1/3/5；累计分最低的人赢。

## v1 不做

- 递增开牌门槛（后开牌者要超过前一次）。
- 拿回桌上 Okey / 弃 Okey 罚分 / 可加牌未加罚分。
- 双人组队（2v2）。
- 拿弃牌后严格的“必须能开牌”搜索：现在只检查能否和手牌组成一个合法牌型；拿后如果发现用不了，可以点“放回弃牌堆并摸牌”（数字版便利，实体通常罚分）。
- “顺子每端每回合最多加 2 张”在完整分组提交模型下不单独限制。
