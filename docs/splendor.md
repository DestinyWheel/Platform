# 璀璨宝石（Splendor）+ 城市扩展

2–4 人基础版，外加《城市扩展》里的三个模块（可以单开，也可以混开）：

- **繁华之城（Cities）**：不摆贵族，改抢 3 座城市；拿到一块城市板块，本轮走完即结束
- **荣誉之战（Strongholds）**：每人 3 个要塞，占领关键牌、三堡压顶可以再买一次
- **贸易之路（Trading Posts）**：回合末满足条件就占下一条能力，永久生效

扩展开房时选择，可以同时开多个，Elo 按实际组合分榜（见 [extensions.md](extensions.md)）。
官方规则书要求四个模块单独使用，但 BGA 允许混开；这里按混开来做。

规则来源：根目录 `璀璨宝石（Splendor）+ 城市扩展.docx`（全部是规则书截图，共 12 页），
细则对照 [UltraBoardGames 的官方规则转写](http://ezmail.ultraboardgames.com/splendor/cites-of-splendor.php)。

卡表来源：[bouk/splendimax 的 Splendor Cards.csv](https://github.com/bouk/splendimax/blob/master/Splendor%20Cards.csv)
（等级 / 红利色 / 分数 / 五色价格），已按官方分布核对：40 / 30 / 20 张，五色各 8 / 6 / 4 张。
城市板块的 14 个面按实物数值录入。

## 基础规则

- 90 张发展卡：等级 1 / 2 / 3 各 40 / 30 / 20；每级正面朝上 4 张，买走或预留后立刻补同级的牌
- 宝石 5 色 + 黄金；2 / 3 / 4 人局每种宝石 4 / 5 / 7 个，黄金恒 5 个；贵族正面 3 / 4 / 5 张
- 每回合四选一：
  - 拿 3 个不同颜色
  - 拿 2 个同色（该色场上至少 4 个才允许）
  - 预留 1 张卡（上限 3 张，可以从牌堆顶盲抽），同时拿 1 个黄金
  - 买 1 张卡（场上的或自己预留的）
- 红利永久抵扣同色价格；不够的部分用黄金补
- 回合结束手上超过 10 个指示物（含黄金）要弃回
- 贵族在回合结束自动拜访，同时满足多个才让玩家选，一次一个
- 有人到 15 分后**打完本轮**结束；分高者胜，同分则买卡少的人胜
- 预留的牌只有本人能看到牌面

## 繁华之城

- 不摆贵族；7 张城市板块洗混后随机抽 3 张，每张随机一面朝上
- 回合结束（弃指示物之前）检查：声望 ≥ 板块分数，且红利满足板块要求
- 同时满足多块时选一块（每人只能有一块城市板块）
- 有人拿到板块后，本轮走完即结束：只有一个人拿到他赢；多人拿到则其中声望最高的赢
- 本模块**没有 15 分终局**，结束条件只看城市板块

城市要求有三种写法：

| 写法 | 含义 |
|---|---|
| `fixed` | 指定颜色各几个（如 4 绿 + 3 蓝） |
| `any` | 同一种颜色 N 个，玩家自选是哪一色 |
| `anyOther` | 指定颜色 N 个 + 另一任意颜色 N 个 |
| `none` | 只要声望分（比萨 17 分那面） |

## 荣誉之战

- 每人 3 个要塞（按座位配色）
- 每次**买卡**后、补牌前，必须二选一：把自己的要塞放到一张没有其他颜色要塞的正面朝上牌上（可以叠自己的），或拆掉对手一个
- 1–2 个要塞 = 占领：这张牌只有该玩家能买或预留，买/预留时收回要塞
- 3 个要塞 = 控制：该玩家行动结算后可以立刻买下这张牌（付钱、收回要塞、再放/移一个要塞，然后才补牌）
- 抢占购买发生在贵族拜访和指示物上限检查之前

## 贸易之路

- 版图上 5 条能力，每条能力给每个座位留一格（5 × 4 = 20，正好对上 20 枚纹章）
- 回合结束（贵族之后）满足某条能力的要求，就从自己的 5 枚纹章里放一枚上去，能力永久生效
- 同一条能力可以被不同玩家各占一枚；同一个人也可以占多条能力
- 5 条能力：

| 要求 | 效果 |
|---|---|
| 3 红 + 1 白 | 每次买卡后拿 1 个宝石（放纹章那回合不触发） |
| 2 白 | 拿 2 个同色时，额外拿 1 个其他颜色 |
| 3 蓝 + 1 黑 | 购买时每个黄金当 2 个同色宝石（指示物上限仍按 1 个算） |
| 5 绿 | 你在版图上每有 1 枚纹章，就值 1 点声望（含刚放的这枚） |
| 3 黑 | 从牌堆顶盲抽预留时，摸两张、挑一张留下，另一张放回牌堆底 |

后两条是房规改编：原版「5 绿 + 1 贵族 → 立刻 5 分」和「3 黑 → 每枚纹章 1 分」，
按用户的要求改成了现在这样。

```

  src/rules.ts     # 红利汇总、付款规划（含黄金顶 2 颗）、贵族 / 城市判定
  src/server.ts    # 回合状态机、三个扩展钩子、legalMoves、view 裁剪
  src/client.ts    # 棋盘、玩家面板、扩展面板（内联 CSS，无图片）
```

## 回合状态机

```
turn ─┬─ 拿三 / 拿二 / 预留 ─────────────────────────┐
      └─ 买卡 → buy-gem（贸易之路）→ stronghold（荣誉之战）→ 补牌 → conquest
                                                         ↓
                                       noble → seal（贸易之路）→ discard → 城市检查 → 换人 / 结束
```

- `buy-gem` / `extra-gem`：贸易之路的两条"拿宝石"能力
- `stronghold`：买卡后强制放/移/拆
- `conquest`：三堡压顶时的可选购买
- `noble` / `seal` / `city`：同时满足多个时让玩家选
- `discard`：弃到 10 个为止
- 终局：非城市模块 15 分触发、本轮走完结算；城市模块看城市板块

## 边界约定

- **兜底 `pass` 动作**：只有在"桌上宝石全空 + 所有牌都买不起 + 没有可预留"时才会被枚举出来，
  避免死锁。正式规则里没有这个动作，正常对局不会出现。
- **城市板块的"任意"**：指同一种颜色 N 个（不是分散在多个颜色上）。
- **城市板块的"其他"**：指另一种颜色各 N 个（两种颜色都要 N 个）。
- **比萨 17 分那面**：只要声望、没有红利要求。
- **贸易之路版图**：每条能力每个座位一格，先到先得；同一玩家不能在同一条能力上放第二枚。
- **城市模块没有 15 分终局**：到 15 分不会结束，只有拿到城市板块才会。
- **预留牌可见性**：只有本人能看到牌面，对手和观战者只看到背面。
- **混开**：三个模块可以任意组合。开了繁华之城就没有贵族（现在没有能力依赖贵族，
  所以不影响任何一条贸易之路能力）。
- **牌堆二选一**：只有牌堆还剩 ≥2 张时才会摸两张；只剩 1 张就按普通盲抽处理。
  没被选中的那张放回**牌堆底部**（牌堆数组的头部），所以下一次摸顶不会摸到它。
- 数字版不显示实体卡面，全部 CSS 绘制；卡面只放「分数 / 红利宝石 / 要塞标记 / 成本圆点」，
  不写颜色名（颜色靠宝石和悬停提示表达）。
